# CET-мост 2.1

Отчёт из реальной игры подтвердил, что GetTarots требует параметр. Исправлен
вызов: JournalRequestContext.new(), JournalRequestStateFilter.new(), все
четыре состояния true, назначение всего фильтра в ctx.stateFilter, затем
GetTarots(ctx). Отдельные поля фильтра не меняются через копию вложенной структуры.

Структуры и свойства подтверждены приложенным RTTI-дампом; создание контекста
согласовано с опубликованным примером запроса журнала. Тест Lua теперь требует
обязательный контекст и возвращает непустую запись таро: старый вызов без
аргумента этот тест не проходит. Факты, таро и деревья выбранных миссий
читаются независимо, чтобы одна ошибка не уничтожала остальные сведения.

Патч только диагностический. Серые кнопки в EXE v2 означают отсутствие
реализации завершения миссий; данный патч их не включает. Повторный отчёт
нужен для дальнейшего исследования, но сам по себе не доказывает безопасное
или полное завершение цепочки и выдачу награды.
